# Bajo el Mismo Cielo

Página interactiva de regalo: un viaje de scroll con música que cambia por sección, versos de Job y mensajes diarios.

## Ver la página

Abre `index.html` directamente en el navegador (doble clic), o sírvela con cualquier servidor estático:

```bash
python -m http.server 8000
```
